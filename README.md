# 오늘도 생존운동 🏃

**10초 안에 기록하고, 오늘 무엇을 해야 하는지 바로 보여주는** 건강 기록 웹앱입니다.

별도 서버나 유료 데이터베이스 없이 **Google Apps Script 웹앱 → Google Sheet 자동 저장** 구조로 동작합니다.
스마트폰과 PC 어디서나 쓸 수 있고, 입력한 운동·식사·건강 기록이 실시간으로 내 Google Sheet에 쌓입니다.

> 이 앱은 운동과 식사 기록을 위한 개인 생활관리 도구이며, 의료 진단이나 치료를 대신하지 않습니다.
> 흉통, 심한 호흡곤란, 갑작스러운 마비·언어장애·심한 어지럼증 등이 발생하면
> 운동을 중단하고 즉시 응급의료기관에 연락하세요.

---

## 주요 기능

### 🏠 홈 — 오늘의 생존 운동
- `운동계획` 시트를 읽어 **오늘 할 운동을 자동 표시** (12주 기본 계획 자동 생성)
- 항목을 탭 한 번으로 완료 체크 → 즉시 시트에 기록
- 오늘 달성률 / 이번 주 운동일수 / 연속 기록일 표시
- 아침·점심·저녁 식사 기록 여부 한눈에 확인

### 🏃 운동 기록
- 운동 종류, 목표/실제 시간, 횟수·세트, 강도, 완료 여부, **통증 부위**, 운동 후 상태, 메모
- 칼로리 계산보다 "운동을 했는지, 통증이 있었는지, 얼마나 힘들었는지"를 기록하는 데 집중

### 🍚 식사 기록
- 칼로리 입력 없이 10초 기록: 식사 구분, 음식명, 양(적게/보통/많이)
- 핵심 체크 4가지: **채소 · 단백질 · 야식 · 탄산/술** + 포만감(부족/적당/과식)

### ❤️ 건강 기록
- 체중, 혈압(최고/최저/맥박 별도 입력), 걸음 수, 수면시간, 컨디션(1~5), 허리둘레
- 매일 모두 기록할 필요 없이 잰 것만 입력
- 혈압이 높게 입력되면 **"휴식 후 다시 측정하고, 지속되면 의료기관 상담"** 안내만 표시 (자동 진단 없음)

### 📊 주간 리포트
- 숫자 카드: 운동일수, 걷기 시간, 근력운동 횟수, 식사 기록률, 체중 변화, 평균 혈압, 연속 실천일
- 그래프: 최근 12주 체중 추이(선) · 주별 걷기 시간(막대) · 이번 주 달성률(도넛) ·
  식사 기록률(막대) · 혈압 변화(최고/최저 선그래프)

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `Code.gs` | 서버 로직 — 시트 생성/읽기/쓰기, 오늘의 운동 계산, 리포트 집계 |
| `Index.html` | 화면 뼈대 (홈/운동/식사/건강/리포트 + 하단 내비게이션) |
| `Stylesheet.html` | 스타일 (모바일 우선, 큰 버튼·큰 글씨, 라이트/다크 자동) |
| `JavaScript.html` | 화면 동작 — `google.script.run` 서버 호출, Chart.js 그래프 |
| `appsscript.json` | Apps Script 매니페스트 (시간대 Asia/Seoul, 본인만 접근) |

## Google Sheet 구조 (자동 생성)

앱을 처음 열면 아래 시트가 자동으로 만들어집니다. 직접 만들 필요 없습니다.

- **`사용자설정`** — 사용자명 · 시작체중 · 목표체중 · 키 · 시작일 · 주차
- **`운동기록`** — 기록ID · 날짜 · 운동종류 · 목표시간 · 실제시간 · 목표횟수 · 실제횟수 · 세트 · 강도 · 완료여부 · 통증부위 · 운동후상태 · 메모 · 기록시각
- **`식사기록`** — 기록ID · 날짜 · 시간 · 식사구분 · 음식명 · 식사량 · 채소 · 단백질 · 포만감 · 야식 · 음료 · 사진URL · 메모
- **`건강기록`** — 기록ID · 날짜 · 체중 · 최고혈압 · 최저혈압 · 맥박 · 걸음수 · 수면시간 · 컨디션 · 허리둘레 · 메모
- **`운동계획`** — 주차 · 요일 · 운동종류 · 목표시간 · 목표횟수 · 세트 · 설명
  (12주 기본 계획이 자동 입력되며, 시트에서 자유롭게 수정하면 홈 화면에 바로 반영)

개인정보 보호를 위해 약 이름이나 상세 질환 정보는 저장하지 않는 구조입니다.

## 설치 방법 (5분)

1. **Google Sheet 새로 만들기** — [sheets.new](https://sheets.new) 접속, 이름은 자유 (예: "생존운동 기록")
2. 메뉴에서 **확장 프로그램 → Apps Script** 클릭
3. 파일 4개를 만들어 이 저장소의 내용을 그대로 붙여넣기
   - 기본 `Code.gs` 파일에 → `Code.gs` 내용
   - `+` → **HTML** → 이름 `Index` → `Index.html` 내용
   - `+` → **HTML** → 이름 `Stylesheet` → `Stylesheet.html` 내용
   - `+` → **HTML** → 이름 `JavaScript` → `JavaScript.html` 내용
   - (선택) 프로젝트 설정에서 "appsscript.json 표시"를 켜고 `appsscript.json` 내용으로 교체
4. 저장 후 **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **나만** (본인 전용) — 가족과 공유하려면 "링크가 있는 모든 사용자"
5. 웹 앱 URL 접속 → 첫 실행 시 권한 승인 → 시트와 12주 계획이 자동 생성됩니다

### 📱 스마트폰 홈 화면에 추가

- **iPhone**: Safari로 웹앱 URL 열기 → 공유 버튼 → **홈 화면에 추가**
- **Android**: Chrome으로 열기 → 메뉴(⋮) → **홈 화면에 추가**

이후 앱처럼 아이콘을 눌러 바로 기록할 수 있습니다.

### 코드 수정 후 반영

Apps Script 편집기에서 코드를 수정한 뒤에는
**배포 → 배포 관리 → 연필 아이콘 → 버전: 새 버전 → 배포**를 눌러야 웹앱에 반영됩니다.

### 로컬 미리보기 (개발용)

배포 없이 화면만 확인하려면 `Index.html`의 `<?!= include(...) ?>` 부분을
`Stylesheet.html`/`JavaScript.html` 내용으로 치환해 브라우저로 열면
목데이터 기반으로 동작합니다. (`google.script`가 없으면 자동으로 목모드)

## 개발 로드맵

- **1차 (구현됨)**: 오늘 운동 표시 · 완료 체크 · 식사 간단 기록 · 체중/혈압 기록 · Sheet 저장 · 최근 기록 조회
- **2차 (구현됨)**: 오늘 달성률 · 주간 운동일수 · 체중 변화 그래프 · 연속 기록일 · 주간 리포트
- **3차 (예정)**: 식사 사진 업로드(Google Drive) · 지난 식사 불러오기 · 월간 리포트 · PDF 리포트 · 격려 메시지

## 안전 설계 원칙

- 앱은 **기록 및 생활관리 도구**이며 진단 도구가 아닙니다
- 비정상 수치 입력 시 자동 진단 없이 "의료기관 상담을 고려하세요" 수준의 안내만 표시
- 운동을 강제로 금지하거나 약 복용을 지시하는 기능은 넣지 않습니다
